## Runtime evaluation criteria

Evaluate each runtime by:

- Windows support
- CPU support
- Intel Iris Xe support
- AVX2 support
- Local HTTP API
- Loopback binding
- Structured JSON support
- Streaming support
- Cancellation behaviour
- Model-file control
- Quantization support
- Logging
- Licence
- Installation footprint
- Uninstall/rollback procedure
- Compatibility with SIONA `LocalOpenWeightProvider`
- Long-term replaceability
